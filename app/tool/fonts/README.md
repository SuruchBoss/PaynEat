# ฟอนต์สำหรับเครื่องมือถ่ายภาพหน้าจอ

`flutter_test` ไม่มีฟอนต์ระบบให้ใช้ ถ้าไม่โหลดฟอนต์เข้าไปเอง ตัวอักษรทั้งหมดจะถูกวาดเป็นกล่องทึบ
ไฟล์ฟอนต์จริงอยู่ที่ `app/assets/fonts/` (ที่เดียวกับที่แอปใช้) แล้วถูกโหลดเข้า test binding
ตอนถ่ายภาพหน้าจอ (ดู `tool/screenshots/screenshot_harness.dart` และ `docs/video/build.sh`)
โฟลเดอร์นี้เหลือไว้เป็นที่บันทึกที่มา/สัญญาอนุญาตของฟอนต์เท่านั้น ไม่ต้องวางไฟล์ซ้ำที่นี่อีก

ใช้เฉพาะตอนสร้างเอกสารเท่านั้น ไม่ได้ถูกรวมเข้าไปในแอปที่ build ออกไปจริง
