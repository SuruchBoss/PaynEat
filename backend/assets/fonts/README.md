# ฟอนต์สำหรับ PDF เอกสารลูกหนี้

ใช้โดย `src/core/documentPdf.js` (ใบวางบิล ใบเสร็จรับเงิน ใบลดหนี้ ใบแจ้งดอกเบี้ยผิดนัด —
ดู `docs/tickets/23-document-pdf-email.md`) เป็นไฟล์เดียวกับ `app/assets/fonts/NotoSansThai-*.ttf`
ที่แอปใช้ มีตัวอักษรไทย ละติน ตัวเลข และ ฿ ครบในไฟล์เดียว จึงไม่ต้องสลับฟอนต์กลางบรรทัด
