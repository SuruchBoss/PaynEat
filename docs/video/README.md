## วิดีโอเล่าอะไรบ้าง

16 ฉาก เรียงตามเส้นทางการใช้งานจริงของร้าน:

1. หน้าปก + สรุป stack
2. โจทย์ที่ระบบนี้แก้
3. 3 บทบาทผู้ใช้ (พนักงานเสิร์ฟ / ครัว / ผู้จัดการ)
4. **01–11** ภาพหน้าจอจริงของแอปพร้อมคำบรรยาย — เปิดผังโต๊ะ, รับออเดอร์,
   เลือกตัวเลือกอาหาร, ตะกร้า, จอครัว, เสิร์ฟ, เช็คบิล, ชำระเงิน,
   แดชบอร์ดผู้จัดการ, จัดการเมนู, จัดการพนักงาน
5. ตัวเลขเบื้องหลัง (เทสต์ 82 ตัว, Clean Architecture 3 ชั้น, 31 API endpoints)
6. ฉากปิดพร้อมคำสั่งรัน

## ภาพในวิดีโอมาจากไหน

ทุกภาพเป็นภาพหน้าจอจริงที่เรนเดอร์จากโค้ดล่าสุด ไม่ใช่ mockup:

```bash
cd app
flutter test --update-goldens tool/screenshots/capture_test.dart
```

harness ตัวนี้บูตแอปจริงในโหมด Demo Mode, ล็อกอินตามบทบาท, seed ข้อมูล
แล้วแคปหน้าจอทั้ง phone (390×844), tablet (1194×834) และ desktop (1440×900)
ผลลัพธ์อยู่ที่ `app/tool/screenshots/images/`

## สร้างวิดีโอใหม่

```bash
cd docs/video && npm install   # ครั้งแรกครั้งเดียว (ลง playwright + chromium)
cd ../.. && ./docs/video/build.sh   # ทั้ง TH และ EN
./docs/video/build.sh th           # เฉพาะภาษาไทย
```

ต้องมี `python3`, `node` และ `ffmpeg` อยู่ในเครื่อง

ขั้นตอนที่สคริปต์ทำ:

1. `build_video_html.py` อ่านสตอรีบอร์ดจาก `storyboard.py`
   แล้วเขียนหน้า HTML 1920×1080 หนึ่งหน้า ที่ทุกแอนิเมชันเป็น CSS keyframes
   ล้วน ๆ ตั้ง `animation-delay` ตามเวลาในวิดีโอ — ไม่มี JavaScript
   ควบคุมจังหวะเลย ทำให้ผลลัพธ์คงที่ไม่ว่าจะเรนเดอร์กี่ครั้ง
2. `record.mjs` เปิดหน้านั้นใน Chromium (Playwright) ขนาด 1920×1080
   พักแอนิเมชันไว้จนฟอนต์และรูปโหลดครบ แล้วรีเซ็ต `currentTime` เป็น 0
   พร้อมกันทุกตัวก่อนเริ่มอัด → ได้ไฟล์ `.webm` (VP8)
3. `ffmpeg` แปลงเป็น H.264 MP4 พร้อมตัดช่วงโหลดหน้าตอนต้นออก

### แก้เนื้อหา

แก้ที่ `storyboard.py` อย่างเดียว (`STORYBOARD_TH` / `STORYBOARD_EN`)
ไฟล์นั้นเก็บเฉพาะเนื้อหา — หัวข้อ, คำบรรยาย, ชื่อไฟล์ภาพ, ความยาวแต่ละฉาก
ส่วน `build_video_html.py` เก็บเฉพาะ layout กับแอนิเมชัน

> หมายเหตุ: UI ในแอปเป็นภาษาไทย ฉบับ EN จึงเป็นคำบรรยายภาษาอังกฤษ
> ประกอบภาพหน้าจอภาษาไทย
