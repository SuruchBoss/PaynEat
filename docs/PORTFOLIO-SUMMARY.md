# PaynEat POS

**ระบบขายหน้าร้าน (POS) สำหรับร้านอาหาร — full-stack ตั้งแต่หน้าเสิร์ฟถึงหลังบ้าน**
Flutter (มือถือ/แท็บเล็ต/เว็บ) + Node.js/Express (backend) พร้อม business logic จริงของร้านอาหาร
ไม่ใช่แค่ CRUD demo — [ลองเล่นได้จริง](https://suruchboss.github.io/PaynEat/) · [โค้ดเต็ม](https://github.com/SuruchBoss/PaynEat)

## ทำไมถึงไม่ใช่แค่ CRUD demo

- **คำนวณเงินถูกต้องทุกครั้ง** — VAT, Service Charge, ส่วนลด/โปรโมชัน คิดที่ backend ฝั่งเดียว ไม่พึ่งเครื่องไคลเอนต์ที่อาจถูกแก้ไข ใช้เลขจำนวนเต็ม (สตางค์) ล้วน ไม่มีปัญหาปัดเศษทศนิยม
- **Audit trail ที่แก้ไข/ลบไม่ได้** — ทุก action ที่กระทบเงิน (ยกเลิกออเดอร์, คืนเงิน, เปิด/ปิดกะ, ใช้/ยกเลิกโปรโมชัน) บันทึกอยู่ใน database transaction เดียวกับการเปลี่ยนแปลงจริง ถ้าบันทึก log ไม่สำเร็จ การกระทำนั้นต้องล้มเหลวไปด้วย
- **PromptPay QR ของจริง** — สร้างตามมาตรฐาน EMV QR ผูกยอดเงินอัตโนมัติ มีเทสต์คู่ (backend JS + Flutter Dart) พิสูจน์ว่าทั้งสองฝั่งให้ผลลัพธ์ตรงกันทุกไบต์
- **ผู้ช่วย AI ที่ตอบจากข้อมูลจริงผ่าน tool-calling ไม่ใช่ chatbot ประดับ** — เชื่อม Claude API เข้ากับ endpoint เดิมของระบบ (ไม่แตะ DB ตรงๆ) ทุกคำตอบระบุแหล่งข้อมูล/tool ที่ใช้ตรวจสอบย้อนกลับได้เสมอ พร้อมจำกัดโควตาต่อวันกันค่าใช้จ่ายบานปลาย
- **พิมพ์ใบเสร็จจริงผ่าน ESC/POS Bluetooth**, โหมดออฟไลน์รับออเดอร์ต่อได้ตอนเน็ตหลุด, ระบบแต้มสะสมลูกค้า, ย้ายโต๊ะ/รวมบิล/แยกบิลรายคน
- **สิทธิ์ตามบทบาทบังคับที่ server ไม่ใช่แค่ซ่อนปุ่มในหน้าจอ** — เรียก API ตรงก็ยังถูกเช็คสิทธิ์อยู่ดี

## Stack

**Frontend**: Flutter · GetX (state management) · Clean Architecture
**Backend**: Node.js · Express · SQLite · Socket.IO (real-time sync ทุกอุปกรณ์)
**Deploy**: Docker Compose, รันได้ทั้งระบบในเครื่องเดียว ไม่ต้องพึ่งอินเทอร์เน็ต
