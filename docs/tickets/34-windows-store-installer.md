# Ticket: ตัวติดตั้ง Windows สำหรับร้านจริง ให้เจ้าของร้านที่ไม่มีพื้นฐานไอทีติดตั้งเองได้

**สถานะ (2026-10-09):** ⏳ ยังไม่ได้ทำ — ต้องรอเจ้าของโปรเจกต์ตอบคำถามในหัวข้อ "ต้องตัดสินก่อนเริ่ม" ก่อน
**Ref:** `docs/DECISIONS.md` #99 (จุดพักและประตูก่อนร้านจริง), #93, #65 (ตัวติดตั้งเดโม), #72 (คู่มือติดตั้ง), #83 (ค่าเริ่มต้นสำหรับ production),

**Blocked by:** T20 #98 และ T23 #87 ต้องเสร็จก่อน เพราะตัวติดตั้งเปิดระบบให้ทุกเครื่องในวง LAN ของร้านเข้าถึงได้

## ปัญหา
ตอนนี้มีทางติดตั้ง 4 ทาง แต่ไม่มีทางไหนที่เจ้าของร้านทั่วไปใช้กับร้านจริงได้เอง:
- ทางเลือก A และ B ต้องใช้ git, Node หรือ Docker, แก้ไฟล์ `.env` และตั้ง secret เอง ซึ่งต้องมีคนไอทีช่วย
- ทางเลือก D (`install-demo.ps1`) ติดตั้งง่าย แต่ใช้ได้กับเดโมเท่านั้น `JWT_SECRET` ถูกเผยแพร่สาธารณะ บัญชีเริ่มต้นเป็น `admin123` และยังต้องมี Docker Desktop ด้วย
- ทุกทางที่ build แอปเว็บจะผูก `API_BASE_URL=http://localhost:3000` ไว้ แท็บเล็ตกับมือถือในร้านจึงเข้าสู่ระบบไม่ได้จนกว่าจะตั้ง IP แล้ว build ใหม่
  (`docs/FEATURE-GAP-ANALYSIS.md` หัวข้อคู่มือติดตั้ง)

เป้าหมายคือเจ้าของร้านดาวน์โหลดไฟล์เดียว ดับเบิลคลิก กดถัดไปจนจบ ตั้งชื่อร้านกับรหัสผ่าน แล้วทุกเครื่องในร้านเปิดที่อยู่เดียวกันได้ทันที

## ต้องตัดสินก่อนเริ่ม (เจ้าของโปรเจกต์)
1. **ใบรับรอง code signing** — ถ้าไม่ลงนาม Windows SmartScreen จะขึ้น "Windows protected your PC" และเจ้าของร้านต้องกด More info → Run anyway
   การลงนามต้องซื้อใบรับรองรายปี ข้อนี้เป็นเรื่องค่าใช้จ่าย เจ้าของโปรเจกต์ต้องเป็นคนตัดสิน ถ้ายังไม่ซื้อ คู่มือติดตั้งต้องมีภาพหน้าจอขั้นตอนกด Run anyway
2. **Windows อย่างเดียวก่อน** — PO แนะนำให้เริ่มที่ Windows 10/11 x64 เพราะเป็นเครื่องที่ร้านมีอยู่แล้ว ส่วน macOS และ Linux ไว้ทีหลัง
3. **ไม่ใช้ Docker** — PO แนะนำให้รวม Node runtime ไว้ในตัวติดตั้งเลย ไม่ต้องติดตั้ง Docker Desktop เพราะ Docker Desktop ต้องใช้ WSL2 หรือ Hyper-V
   บางเครื่องต้องเข้า BIOS ไปเปิด virtualization เอง และกินแรมตลอดเวลา ซึ่งเจ้าของร้านทั่วไปทำเองไม่ได้

## ขอบเขตงาน (ตามที่ PO แนะนำในข้อ 2–3)

### 1. ไฟล์ติดตั้งไฟล์เดียว
- `PaynEat-Setup-<version>.exe` CI build จาก tag ประกอบด้วย Node runtime ที่ล็อกเวอร์ชันไว้, backend พร้อม dependency สำหรับ production
  (รวม better-sqlite3 ที่ build สำหรับ win-x64) และแอปเว็บที่ build แล้ว
- ตัวติดตั้งรองรับภาษาไทย อังกฤษ และเกาหลี
- ติดตั้งโปรแกรมไว้ใน `Program Files\PaynEat` แยกข้อมูลไว้ใน `ProgramData\PaynEat` (ฐานข้อมูล ไฟล์สำรอง และ log) อัปเดตหรือถอนโปรแกรมแล้วข้อมูลไม่หาย

### 2. ทุกเครื่องในร้านเปิดที่อยู่เดียวกันได้
- backend เสิร์ฟแอปเว็บเองบนพอร์ตเดียวกับ API (same origin) และแอปเว็บที่ไม่ได้ระบุ `API_BASE_URL` ให้เรียก API จากที่อยู่ของหน้าเอง
  ปิดช่องว่าง "มือถือยิง localhost ของตัวเอง" แบบถาวร (ทางเลือก B ก็ได้ประโยชน์จากข้อนี้ด้วย)
- เพิ่ม firewall rule ให้พอร์ตนี้เฉพาะ network profile แบบ Private ห้ามเปิดบน Public
- หน้าจบการติดตั้งและไอคอนบนเดสก์ท็อปแสดงที่อยู่ในวง LAN พร้อม QR ให้แท็บเล็ตสแกนเข้า

### 3. ทำงานเป็น Windows service
- เปิดเครื่องแล้วระบบทำงานเองโดยไม่ต้องล็อกอิน Windows และไม่มีหน้าต่างให้เผลอกดปิด
- ถ้า service หยุดเอง ให้เริ่มใหม่อัตโนมัติ และเขียน log ลงไฟล์โดยไม่มี secret หรือข้อมูลลูกค้าปนอยู่

### 4. ตั้งค่าครั้งแรกบนเบราว์เซอร์
- ตัวติดตั้งสุ่ม `JWT_SECRET` และ secret อื่นที่ต้องใช้ เก็บไว้ในไฟล์ที่ให้สิทธิ์อ่านเฉพาะ service กับ Administrators และใช้ค่าเริ่มต้นของ production ตาม #83
- ห้ามมีบัญชี `admin123` ในเครื่องที่ติดตั้งด้วยตัวนี้ เปิดครั้งแรกให้ตั้งชื่อร้าน ชื่อผู้ใช้ และรหัสผ่าน admin เอง
- แนะนำให้ตั้ง `BACKUP_COPY_DIR` บนอีกดิสก์หรือ USB ตาม ticket 33 (ข้ามได้ แต่แถบเตือนต้องแสดงต่อจนกว่าจะตั้ง)

### 5. อัปเดต กู้คืน และถอนการติดตั้ง
- อัปเดตด้วยการรันไฟล์เวอร์ชันใหม่: หยุด service → แทนไฟล์โปรแกรม → เปิด service ซึ่งจะสำรองข้อมูลก่อน migration ตาม ticket 33 ห้ามลงเวอร์ชันที่เก่ากว่าที่ติดตั้งอยู่
- เมนู Start มีทางลัด "กู้คืนข้อมูล" ที่หยุด service เรียก `db:restore` กับไฟล์ที่เลือก แล้วเปิด service ให้เอง เจ้าของร้านไม่ต้องพิมพ์คำสั่ง
- ถอนการติดตั้งแล้วข้อมูลใน `ProgramData\PaynEat` ยังอยู่ ยกเว้นผู้ใช้ติ๊กเลือกให้ลบเอง พร้อมคำเตือน

### 6. คู่มือ
- เพิ่มทางเลือก "ติดตั้งสำหรับร้านจริงบน Windows" เป็นการ์ดแรกของหน้า `install*.html` ทั้งสามภาษา (#72) และ README ทั้งสามภาษา
- ทางเลือก D ยังคงอยู่สำหรับเดโม โดยเขียนให้ชัดว่าแตกต่างจากตัวติดตั้งร้านจริงอย่างไร

## Acceptance criteria
- [ ] บนเครื่อง Windows 11 ที่ไม่มี Node, Docker หรือ git ดับเบิลคลิกไฟล์เดียวแล้วติดตั้งจนเปิดหน้าตั้งค่าครั้งแรกได้ โดยไม่ต้องพิมพ์คำสั่งเลย
- [ ] แท็บเล็ตในวง LAN เดียวกันเปิดที่อยู่ที่หน้าจบการติดตั้งแสดงไว้ แล้วล็อกอินและรับออเดอร์ได้โดยไม่ต้องตั้งค่าเพิ่ม
- [ ] รีสตาร์ตเครื่องแล้วระบบกลับมาทำงานเองโดยไม่ต้องล็อกอิน Windows
- [ ] ไม่มีบัญชีหรือ secret ค่าเริ่มต้นที่เผยแพร่สาธารณะ และสองเครื่องที่ติดตั้งจะได้ `JWT_SECRET` ไม่ซ้ำกัน
- [ ] อัปเดตจากเวอร์ชันก่อนหน้าแล้วบิล กะ และลูกค้าครบเหมือนเดิม และมีไฟล์สำรองก่อน migration
- [ ] กู้คืนข้อมูลผ่านทางลัดในเมนู Start ได้โดยไม่ต้องเปิด command prompt
- [ ] ถอนการติดตั้งแบบค่าเริ่มต้นแล้วฐานข้อมูลกับไฟล์สำรองยังอยู่ ติดตั้งใหม่แล้วกลับมาใช้ข้อมูลเดิมได้

## เทสต์
- CI บน `windows-latest`: ติดตั้งแบบ silent → `/health` ตอบ → ตั้งค่าครั้งแรกผ่าน API → ล็อกอิน → สร้างบิล → อัปเดตเป็น build ใหม่ → บิลยังอยู่
  → ถอนการติดตั้ง → ข้อมูลยังอยู่
- เทสต์ฝั่งแอปที่ตรวจว่าเมื่อไม่ระบุ `API_BASE_URL` แอปเรียก API จากที่อยู่ของหน้า
- เทสต์ฝั่ง backend ที่ตรวจการเสิร์ฟแอปเว็บแบบ same origin และตรวจว่า route ของ API ไม่ถูกแอปเว็บทับ

## ไม่อยู่ในขอบเขต
- ตัวติดตั้ง macOS และ Linux, อัปเดตอัตโนมัติ, ส่งไฟล์สำรองขึ้นคลาวด์ และ HTTPS ภายในร้าน (ใช้ HTTP ในวง LAN แบบเดียวกับทางเลือก B ไปก่อน)
